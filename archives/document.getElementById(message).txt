document.getElementById(message)
document.querySelector(#message)

Lequel choisir ? 


🔍 1. document.getElementById('message') 

    Spécifique : ne marche qu’avec les ID. 

    Pas besoin de # : tu passes juste le nom de l’ID ('message'), sans le dièse. 

    Retourne directement l’élément (ou null si pas trouvé). 

    Ultra rapide : c’est l’une des méthodes les plus performantes, car c’est optimisé pour ça. 

🟢 À utiliser quand tu connais l’ID exact de l’élément que tu veux récupérer. C’est clair, net, efficace. 
🧷 2. document.querySelector('#message') 

    Plus flexible : tu peux utiliser des sélecteurs CSS (#id, .class, div > p, etc.). 

    Demande le # pour un ID, parce que c’est un sélecteur CSS. 

    Retourne le premier élément qui matche le sélecteur (ou null si rien trouvé). 

    Moins rapide que getElementById, mais c’est négligeable dans 99% des cas. 

🟢 À utiliser quand tu veux une syntaxe CSS ou que tu ne travailles pas qu’avec des ID (par exemple si tu veux le premier .card.active dans une liste). 
⚖️ Alors, lequel choisir ? 
Situation    Méthode recommandée 
Tu as un ID et rien d’autre    ✅ getElementById 
Tu veux utiliser un sélecteur CSS    ✅ querySelector 
Tu veux matcher une classe, un type de balise ou une structure complexe    ✅ querySelector 
🎯 En résumé :

    getElementById('message') : plus rapide, plus simple, parfait pour les IDs. 

    querySelector('#message') : plus polyvalent, indispensable dès que tu bosses avec autre chose que des IDs. Tu peux utiliser des sélecteurs CSS (#id, .class, div > p, etc.).
